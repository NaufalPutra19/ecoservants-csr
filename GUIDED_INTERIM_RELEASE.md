# EcoServants CSR Guided Interim Release 1.1.0

This release preserves the existing CSR post type, submission handler, field names, totals, photos, Wall of Fame, and reporting compatibility while adding a future-facing volunteer workflow.

## Included

- Five-step mobile-first guided report experience
- Individual, volunteer-team, and organization reporting paths
- Optional organization, department/group, campaign, and internal-reference metadata
- Touch-friendly material category cards
- Existing weight and subcategory fields shown only when selected
- Browser-based draft saving and restoration
- Live photo previews
- Full review screen with edit controls
- Sticky Back/Continue navigation
- Improved progress indicator, accessibility, focus handling, and reduced-motion support
- Corporate pathway preview for future dashboards, goals, badges, and branded reporting

## Compatibility

No existing `csr_*` field names were renamed or removed. Existing report totals and public displays continue to use the same stored data. New organizational fields are optional metadata and do not affect calculations.
